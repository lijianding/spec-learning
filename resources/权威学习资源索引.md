# 推荐学习顺序

如果你零基础：

1. IREB Foundation 中文 Syllabus
2. 本仓库 00–06
3. MDN HTTP
4. Microsoft API Design
5. Microsoft Relational Data
6. Azure Architecture Center
7. OWASP API Security
8. ISTQB CTFL
9. GitHub Docs
10. IREB AI4RE

不要一开始直接啃所有标准原文。先用本仓库中文教材建立框架，再回原始资料深化。
